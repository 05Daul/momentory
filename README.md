### 2. 주요 기능

### 🏢 블로그 서비스

- 게시물 작성
- 댓글, 대댓글
- 게시물 조회(인기, 최신, 친구)
- 채팅 관련 친구 추가 및 친구 수락

### 📄 커뮤니티 서비스

- 고민 등록 커뮤니티
- 프로젝트 관련 커뮤니티

### 🧑‍💼 회원가입 서비스

- 회원 등록
- 회원 로그인 및 인증 (JWT 기반)

### 🔐 인증 및 보안 서비스

- JWT 기반 토큰 발급 및 갱신
- 사용자 인증 처리 
- 서비스 간 인증 (Feign + Gateway + Spring Security)
